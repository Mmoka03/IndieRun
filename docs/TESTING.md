# 테스트와 검증 범위

## 실행

```powershell
python tools/run_checks.py
python tools/run_checks.py RestoreFlowChecks BackupChecks MoveChecks
python tools/run_checks.py --all
```

기본은 CompositionChecks, RestoreFlowChecks, StatusChecks입니다. `--all`은 모든 `*Checks` 프로젝트를 실행합니다. 이름을 지정하면 해당 묶음만 실행합니다. 테스트별 인자 차이와 LaunchProbe 빌드는 실행 도구가 처리합니다.

테스트 파일은 전용 임시 폴더에 생성하고, JSON 결과와 빌드·실행 로그는 `artifacts/checks` 아래의 새 폴더에 저장합니다. 생성 폴더는 문제 확인을 위해 남깁니다. 결과에는 로컬 절대 경로가 들어갈 수 있으므로 커밋하거나 그대로 공개하지 않습니다.

```powershell
python tools/run_checks.py --output .\artifacts\checks\local-run --timeout 600
```

출력 폴더가 이미 있으면 덮어쓰지 않습니다. 실패·시간 초과는 종료 코드 1로 반환합니다. 시간 초과 시 실행 도구가 시작한 해당 테스트 프로세스 트리를 종료합니다. 실제 사용자 게임을 테스트 인자로 전달하지 마세요.

## 주요 검사

| 영역 | 검사 예시 |
|---|---|
| 탐색 | 범위 경계, 큰 탐색, 중단, 등록 범위 유지 |
| 구성 | 하위 폴더 제외, 관련 자료 연결, 등록된 범위 보호 |
| 식별 | 복사본 ID, 위치 변경, 손상된 식별 정보, 잘못된 자동 연결 방지 |
| 파일 작업 | 백업, 이동, 부분 이동, 되돌리기, 복원, 파일 잠금과 권한 거부 |
| 중단·복구 | 생성한 자식 프로세스 종료 후 재개, 원본 변경 시 중단 |
| UI | 버튼 노출, 화면 배치, 취소, 포커스, 편집 보존, 경고창 |

ACL 권한 거부 검사는 일반 Windows 사용자 환경에서 실행합니다. 제한된 자동화 환경에서는 거부 조건이 다르게 적용될 수 있으므로, 이 경우 원인과 실행 환경을 기록하고 별도 생성 자료로 재검증합니다. 실제 디스크를 가득 채우지 않고 용량 부족 조건을 주입하는 검사도 있습니다.

## 검증 한계

자동 테스트는 생성 자료로 프로그램 동작을 검사합니다. 모든 실제 게임의 필수 파일, 실행·세이브 정상 여부, 버전 동일성을 보장하지 않습니다. 실제 게임 확인은 원본을 보관한 복사본으로 사용자가 수행합니다. 게임 이름과 태그를 검수 자료에 포함할 필요는 없습니다.

UI 검증에는 WPF 레이아웃·렌더링과 동작 테스트가 포함됩니다. 실제 OS 배율별 확인 여부는 해당 변경에서 별도로 기록해야 하며, 레이아웃 검사만으로 모든 DPI 검증을 했다고 판단하지 않습니다.

2026-11-18의 폴더 제외·복원 수정에서는 관련 10개 묶음의 219개 검사가 최종 통과했습니다. 이는 당시 관련 검사 수이며 전체 프로젝트 테스트 수와 같다는 의미는 아닙니다. 최신 결과는 직접 실행한 `summary.json`을 기준으로 확인하세요.
