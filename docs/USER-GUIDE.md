# 사용 방법

## 게임 가져오기

1. 실행 화면의 ‘게임 가져오기’에서 탐색할 폴더를 선택합니다.
2. 정리 화면에서 후보와 폴더 구성을 확인합니다.
3. 가져올 게임을 선택하고 ‘게임 가져오기’를 누릅니다.
4. ‘이 위치에서 사용’은 파일을 이동하지 않고 실행 목록에 등록합니다. ‘보관함으로 옮기기’는 확인한 폴더 범위를 실제로 이동합니다.

이동 전 백업 만들기가 기본 선택입니다. 백업을 해제하면 파일 사본을 남기지 않으므로, 이후 삭제·손상된 파일을 백업에서 복원할 수 없습니다. 진행 전 도착 위치와 필요한 공간을 확인하세요.

## 폴더 구성

정리 화면의 ‘⋯ → 구성 수정’에서 하위 폴더를 본편·관련 콘텐츠·별도 게임·포함하지 않음으로 지정합니다. 구성 적용은 계획을 저장하며 그 자체로 게임 파일을 이동하지 않습니다.

‘포함하지 않음’으로 지정한 폴더는 이동 대상과 해당 이동용 백업에서 제외되어 원래 위치에 남습니다. 실행 파일이 있는 하위 폴더도 본편의 필수 데이터일 수 있습니다. 필수 데이터는 함께 포함하세요.

실제로 보호해야 할 다른 항목과 범위가 겹치면 ‘겹치는 항목 보기’에서 이름과 범위를 확인할 수 있습니다. 해당 항목의 정리 화면으로 이동할 때는 적용하지 않은 구성을 취소할지 확인합니다.

## 실행·편집

별칭으로 검색하고 필요하면 원본 이름 포함 검색을 켭니다. 태그 필터는 선택한 조건을 모두 만족하는 게임을 표시합니다. 카드 또는 목록에서 실행하고, 게임의 옵션 메뉴에서 정보와 실행 설정을 편집합니다.

숨김은 기본 목록의 표시를 숨기는 기능입니다. 게임 파일을 삭제하지 않습니다. 태그 삭제는 적용된 게임에서도 해당 태그를 제거하므로 확인 내용을 읽고 진행하세요.

## 되돌리기와 복원

- **원래 위치로 되돌리기**: 이동한 파일을 이전 위치로 되돌립니다. 작업 기록의 이동 항목에서 상세 메뉴를 열어 선택합니다. 파일 변경이나 충돌이 있으면 상태 확인이 필요할 수 있습니다.
- **백업에서 복원**: 저장된 백업으로 새 복원 폴더를 만듭니다. 작업 기록의 백업 또는 연결된 이동 항목, 백업 관리의 ‘복원’에서 시작합니다.

복원할 백업은 해당 기록에서 자동으로 선택합니다. 사용자는 ‘복원할 위치’를 지정하고 ‘복원 시작’을 누릅니다. 기존 파일과 실행 목록의 연결은 유지됩니다. 백업 당시 제외된 자료나 게임 폴더 밖의 세이브는 복원되지 않습니다.

정상 실행 확인 표시는 사용자가 남기는 기록입니다. 프로그램 실행만으로 게임 진행·세이브까지 정상이라고 자동 판정하지 않습니다. 백업을 삭제하기 전에 직접 확인하세요.

## 수동 이동과 ID

폴더 위치를 바꿨다면 다시 검색하고 필요한 경우 게임 폴더를 다시 지정합니다. 같은 ID가 여러 위치에 있으면 복사본을 확인해야 합니다. 같은 ID만으로 서로 다른 게임 버전을 구분하거나 자동으로 합치지 않습니다.

식별 파일과 메타데이터는 게임 폴더와 함께 보관하세요. 게임 파일 이름이나 내부 구조를 임의로 변경하면 실행에 영향을 줄 수 있습니다.
