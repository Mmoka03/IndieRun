# 초기 Git 이력 구성

2026-11-19에 기존 작업 사본과 현재 소스를 바탕으로 주요 단계의 커밋을 구성했습니다. 이 커밋의 작성 날짜는 이력을 정리한 시점이며 과거 개발 당시의 커밋 날짜를 소급한 것이 아닙니다.

기존 작업은 Git 없이 진행되었으므로 모든 중간 편집을 복원하지 않습니다. 남은 소스 사본에서 빌드와 대표 기능 검사가 가능한 단계만 정리했습니다. 사본의 이름이 개발 순서나 모든 기능을 정확히 나타내는 것은 아니므로 실제 변경을 확인해 제목을 붙였습니다.

| 순서 | 작업 | 구성 기준 |
|---|---|---|
| 1 | 저장소 관리·개발 환경 | 파일 제외, 작성자·SDK·줄바꿈, 협업 규칙 |
| 2 | 게임 탐색·백업 이동 | 탐색, 계획 저장, 백업, 이동·복구가 있는 사본 |
| 3 | 실행·정보 편집 | 보관함 등록과 카드 실행·편집 사본 |
| 4 | 구성·관련 콘텐츠 관리 | 폴더 구성과 별도 게임·관련 자료, 기존 다중 선택 포함 |
| 5 | 대규모 탐색·정리 편의 | 대규모 탐색 개선 사본과 관련 테스트 |
| 6 | 식별·이동 복구 안정화 | 2026-11-07 종합 검수 단계 |
| 7 | 폴더 제외 충돌 수정 | 2026-11-18의 구성 판정 및 충돌 확인 변경 |
| 8 | 백업 복원 UI 개선 | 2026-11-18의 복원 진입·위치 선택 변경 |
| 9 | 배포·테스트 도구 | 저장소만으로 생성 가능한 목데이터·패키징·검증 도구 |
| 10 | 사용·개발 문서 | 현재 동작 기준 README와 안내문 |

다중 선택은 구성 관리 사본에 이미 들어 있어 별도로 새 기능처럼 다시 도입하지 않았습니다. 5번은 실제 추가된 대규모 탐색·정리 편의 변경을 기준으로 묶었습니다. 테스트 일부만 보관된 사본에서는 앞 단계의 테스트를 유지하면서 해당 사본의 테스트로 갱신했습니다.

앱이 있는 각 단계에서 앱과 포함된 테스트 프로젝트를 빌드하고 다음 대표 검사를 실행했습니다.

| 단계 | 대표 검사 |
|---|---|
| 2 | WorkspaceChecks, ScanChecks, MoveChecks |
| 3 | PlayerChecks, LibraryChecks |
| 4 | CompositionChecks, MultiChecks |
| 5 | ScanChecks, WideScanChecks, PlannedChecks |
| 6 | CopyIdentityChecks, TransferAuditChecks |
| 7 | CompositionChecks |
| 8 | RestoreFlowChecks, StatusChecks |

새 실행 도구의 기본 검사와 특수 인자를 사용하는 테스트도 확인합니다. 초기 이력 전체의 모든 테스트를 매 커밋마다 실행했다는 뜻은 아닙니다. 상세 실행 결과와 생성 자료는 로컬에 별도로 보관하며 사용자 경로가 포함될 수 있어 커밋하지 않습니다.

프로그램 실행 데이터·개인 게임·백업·태그·배포 바이너리는 이력에 포함하지 않습니다. 이력 구성과 패키징 도구 정리는 실제 사용 중인 앱의 게임 동작을 변경하지 않습니다. 공개 라이선스와 원격 저장소는 별도로 결정합니다.
